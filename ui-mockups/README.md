# APS v2 UI Mockups

这是一套基于项目文档和参考图整理的可落地 UI 原型图，主文件为：

- `aps-ui-mockups.html`：单页静态原型，可用 `#页面名` 切换。
- `screenshots/*.png`：已导出的 1600x1080 页面截图。

当前版本已按用户参考图重做整体壳层：

- 顶部为白色横栏，左侧显示菜单按钮和「轻量级 APS 排产系统」标题。
- 左侧为浅色任务栏，使用线性图标、中文菜单、蓝色浅底选中态。
- 取消深色侧栏、英文代码块、厚重分组卡片和复杂流程卡。
- 主内容区保留卡片、表格、甘特、问题清单等可直接落地的业务模块。

设计原则：

- 左侧导航视觉完全对齐参考图的清爽风格：白底、线性图标、蓝色选中态。
- 菜单顺序按 APS 业务流程组织，不再按旧 demo 页面堆叠。
- 首屏优先显示判断信息：指标、阻塞、风险、下一步动作。
- 排产结果默认从订单级开始，工序级明细放到订单详情页。
- 经营看板默认展示问题清单，而不是大屏图表。
- 旧 demo 页面只作为历史原型资料保留，当前前端主路由不再注册这些入口。
